# Atividade 1

Este projeto foi desenvolvido como parte do Exercício 1 da disciplina de Introdução a Codificação de Jogos Digitais.

O objetivo da atividade é desenvolver uma cena 2D no Unity, utilizando sprites, background com rolagem vertical e posicionamento de uma nave.

Objetivos
Implementar um background com scrolling vertical;
Utilizar sprites no projeto;
Posicionar a nave na cena;
Configurar materiais e shaders;
Trabalhar com Sorting Layers;
Desenvolver um script em C# utilizando MonoBehaviour;
Utilizar Time.deltaTime para garantir um movimento independente da taxa de quadros.
